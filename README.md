Python Practice

Contents

1. Ticket Booking Conditions

File: bookticket.py

A beginner Python exercise that simulates ticket booking eligibility and calculates a ticket price based on predefined conditions.

Concepts practiced:

* Conditional statements (if, elif, else)
* Comparison and logical operators
* Variables and Boolean values
* Basic arithmetic
* Calculating discounts and additional charges

Requirements

* Python 3

How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the following command:

python bookticket.py

Depending on your system, you may need to use python3 instead of python.
